## ⚙️ How to Setup | සම්බන්ධ කරගන්නා ආකාරය

   <br> [![Get Session](https://img.shields.io/badge/Get-Session_ID-orange?style=for-the-badge&logo=whatsapp)](https://your-session-link.com)
2. **Fork කරන්න:** මේ Repo එක ඔයාගේ GitHub එකට **Fork** කරගන්න.
